# 页面文档契约缺口

> 状态：现行 ｜ 日期：2026-09-19

本文只记录阶段 C Office 功能区移植中确认的主仓契约缺口。缺口控件必须保持禁用，不得由界面层拼接源码或绕过 `DocumentKernelDraftRuntime`。

| 控件 | 当前缺口 | 建议补法 | 当前处理 |
| --- | --- | --- | --- |
| 页面外观 | 主仓没有主题令牌与项目模板任务窗格的安全写回请求 | 增加带 scope 与 CAS 上下文的主题令牌编辑请求 | 页面外观组禁用 |
| 行内样式 | 画布 bridge 没有可信文字选区消息，主仓也没有选区样式写回入口 | 增加受校验的 text-range 消息并接入 range edit intent | 行内样式组禁用 |
| 容器布局模式与对齐 | 属性契约目前只暴露 `gap`，没有 display/grid 列数与 align-items 的受管写回 | 在内核中增加容器布局字段的读取、规划和后置校验 | 相关命令禁用；间距使用现有 `gap` |
| 表格、列表、分隔线、图库 | 主仓尚未移植结构化内容和表格补丁的绑定入口 | 分别移植结构化补丁并通过统一 runtime 绑定 | 上下文组对应命令禁用 |

## 阶段 C 工具栏包汇总

本包四组控件均已挂到桌面 `PageDocumentEditor` 的 Office 外壳。页面与视图组为部分完成，画布宽度、作用域和页面内距可用，主题任务窗格禁用。容器布局组为部分完成，`gap` 可用，布局模式、分栏与对齐禁用。行内样式组因文字选区契约缺失而禁用。上下文组为部分完成，图片替换入口复用现有资产选择器和内核链，表格、列表、分隔线与图库命令禁用。

当前共记录 4 条契约缺口。`npm run lint`、`npm run build` 与 `npm run test:page-document` 在四组提交后均通过，最终测试为 495 项通过；最后一次探针补充后会再跑一次完整门禁。下一步优先补文字选区 bridge 与 range edit intent，因为它同时解锁行内字号、字重、装饰和颜色控件。
