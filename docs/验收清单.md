# 原生验收清单

> 状态：现行 ｜ 日期：2026-09-20

本清单只保留尚未由用户在原生产物中确认的项目。验证通过后直接删除对应项；命令行单测和浏览器预览不能替代这些检查。

按「一次准备能连着做完多少」分轮，不按功能分组。第一轮只需要准备一次桌面编辑会话。

## 第一轮：一次 macOS 调试打包版会话

**一次性准备**：打开 macOS 调试打包版，新建或选定一个词条，让它的页面文档同时包含——普通段落（至少两段）、一个受管容器、一张受管图片、一个表格、一个列表、一条分隔线，并确保项目样式里有有效的 `fc-project :root` 规则。准备好之后进入桌面可视编辑，下面 9 项都在这个会话里完成，中途不需要重启应用或换文档。

1. **字号、加粗与对齐写回页面草稿**。操作：选中一个段落，分别使用「开始」功能区的字号、加粗和对齐命令，关闭后重新打开该词条。预期：每次操作只产生一次对应历史步骤，article.html/style.css 通过现有内核写回；重开后字号、字重和对齐保持，撤销与重做可恢复前后状态。

2. **选区行内样式写回**。操作：在画布中拖选一段文字，依次修改字号、加粗、斜体、下划线和主题颜色，再撤销、重做、保存并重开词条。预期：只修改所选文字，未选文字与未知合法源码保持不变；每项操作可撤销重做，重开后格式保留；切换词条或清空选区后控件禁用且不会写入旧节点。

3. **分段与多段粘贴后的后续输入**。操作：在段落中间按 Enter，立即输入文字；再在任一段落粘贴包含空行的多段纯文本，并分别执行撤销、重做。预期：Enter 后的新文字只出现在新段落；多段粘贴按空行生成多个块，整次粘贴一次撤销即可全部退回，重做恢复原结果，其他源码不变。

4. **容器布局字段写回页面草稿**。操作：选中容器，依次切换布局方式、分栏数、纵向对齐和横向分布，再执行撤销、重做并关闭重开词条。预期：控件只提供有限安全值，style.css 经现有内核写回且容器布局保持；作者已有复杂自定义值显示为自定义并保持不变。

5. **表格、列表与分隔线功能区**。操作：选中表格调整行列，选中列表切换项目符号/编号并新增列表项，选中分隔线修改线型和上下留白，再分别撤销、重做并保存重开。预期：每项命令都通过同一页面草稿内核写回，新增节点身份由宿主分配，源码结构与其他内容保持；图库页签仍显示明确的禁用原因。

6. **图片上下文功能区**。操作：选中图片，切换「图片」页签，选择替换图片、打开替代文字或图注详情。预期：替换沿现有资产选择器和内核请求链执行；未选择文字时行内样式组保持禁用并显示原因（这一条可在第 2 项清空选区时顺带确认）。

7. **页面与视图功能区**。操作：切换「页面」和「视图」页签，选择画布宽度，并在选中受管节点时执行页面内距。预期：画布宽度立即更新，页面内距经内核写回并可撤销；图层/布局线切换和开发者信息按各自状态提示处理。

8. **项目主题令牌功能区**。操作：在「页面」页签选择「项目模板」，打开项目默认主题，修改正文颜色或内容宽度并应用，随后撤销、重做并切换页面预览。预期：请求只写入 `fc-project` 的 `:root` 令牌规则，CAS 版本过期时拒绝且不改草稿；修改进入统一页面草稿历史并可撤销，当前会话预览立即反映项目主题。项目模板的持久化与重开验证待项目模板存储接口接入后执行。

9. **搜索正文并定位页面段落**。操作：返回项目词条列表，搜索只出现在某个页面段落中的中文或英文子串，观察结果片段后点击该词条。预期：卡片显示命中段落的文字片段；词条打开后隔离画布通过现有选择命令选中对应节点，同一结果连续点击也会重新定位；标题命中和旧 Markdown 词条不伪造页面节点定位。

## 第二轮：同一会话，需要先备好图片素材

**一次性准备**：在同一个 macOS 调试打包版里另备四份素材——两张内容明显不同的普通封面、一份 GIF 或动画 WebP、一份 16 位 PNG 或 HDR 图。第 11 项要改动派生目录权限，放在本轮最后做，做完记得恢复。

10. **换图后预览刷新**。操作：给同一词条先选择第一张封面，等待列表派生图显示；再选择第二张并返回列表。预期：第二张显示新内容，不复用第一张缓存；原件文件仍可访问。

11. **动画与高位深样本观感**。操作：将动画和高位深样本分别作为封面导入，查看预览或错误提示。预期：动画静态入口明确取首帧；请求动画播放时提示暂不支持；高位深/HDR 不会被悄悄降成错误颜色的普通预览。

12. **失败占位与重试**。操作：换入一张损坏图片，或把派生目录改为不可写，触发封面预览；再恢复文件或权限并重新触发。预期：失败时显示明确占位，不回退完整原图；恢复后能重新生成 WebP。

## 第三轮：各自需要独立环境，无法与前两轮合并

13. **macOS 最低系统版本**。前置：macOS 12.2 与 12.3 两个测试环境，同一份发行构建。操作：分别尝试安装并打开页面编辑。预期：12.2 不在支持范围；12.3 的画布保留项目、词条和组件层叠顺序。

14. **旧 Android WebView 关闭编辑入口**。前置：一台系统 WebView 缺少 `CSSLayerBlockRule` 的 Android 设备。操作：打开词条并尝试进入页面编辑。预期：宿主显示升级系统 WebView 的提示，不能进入无样式画布。

15. **发行构建不要求用户安装 C 开发环境**。前置：macOS、Windows、Linux、Android、iOS 五份发行构建，以及未安装 C 编译器或 libwebp 开发头文件的目标设备。操作：安装、打开并触发封面派生。预期：应用可以使用静态链接的 libwebp 完成派生，终端用户无需额外依赖。本项成本最高，可等其余各项全部通过后再安排。

## 第四轮：公共组件最小纵向切片

**一次性准备**：在 macOS 调试打包版创建一个项目级公共组件定义，准备一个带公开属性和插槽的组件预览资产；再打开一个页面文档用于插入和重开检查。

16. **插入公共组件实例并保持重复实例隔离**。操作：在页面编辑器的「插入」页签按分类选择组件，向同一容器插入两次，分别填写公开属性和插槽内容，保存后关闭并重开词条。预期：两个实例各自保留页面节点 ID、实例 ID、属性和插槽内容；组件内部静态模板文本随定义展开显示，但不额外进入页面段落索引。

17. **公共组件修订与缺失状态**。前置：通过「编辑公共组件」发布同一组件的第二个修订，并在代码模式让一个实例固定旧修订、另一个实例跟随 latest；另备一份删除或不可读定义的页面草稿。操作：重开页面并查看三个实例。预期：固定旧修订继续显示旧模板，latest 实例显示最高修订，缺失或无效定义保留实例引用并显示明确且可区分的状态，不静默删除。

18. **公共组件实例属性编辑与影响边界**。操作：选中组件实例，在属性面板修改定义声明的属性和样式变量，执行撤销、重做、保存并重开；再从「高级」组尝试修改组件内部结构。预期：实例属性只改变当前实例的 `data-fc-prop-*` 与允许的样式变量覆盖；高级操作先提示“此组件来自公共模板，修改会影响 N 个词条”，并提供编辑公共组件与仅为当前内容创建本地副本两个真实操作。

19. **组件资源与删除保护**。前置：组件定义引用项目图片资产，页面中至少有一个实例。操作：尝试删除仍被实例引用的定义，再删除实例后重试删除定义，并删除项目。预期：有引用时删除被拒；解除最后引用后定义与资源依赖按对象层清理，项目删除不留下该项目组件定义或其无范围资产记录。

20. **组件本地化保持根元素与子元素样式**。前置：准备一个由“保存选中内容”创建、定义只有一个可识别根元素，且根元素和子元素分别带节点样式的组件。操作：插入组件实例，记录外观后执行“仅为当前内容创建本地副本”，再检查布局与样式。预期：实例容器保留原标签、class、style 和布局角色；定义根元素仍位于容器内部，根元素与子元素样式在转换前后命中同一批元素，引用改指新的容器节点。

## 第五轮：公共组件用户操作收口

**额外准备**：沿用第四轮的调试打包版项目，再准备第二个引用同一组件的词条、一张项目图片作为预览，以及一个带节点级样式、伪类和媒体查询的受管内容子树。

21. **编辑公共组件并核对影响范围**。操作：让两个词条各插入一个 latest 实例，并在其中一页另放一个固定旧修订实例；从组件卡片或属性面板打开编辑，核对影响范围后修改 HTML、CSS 和预览图并发布。预期：提示中的词条数和实例数只统计 latest 实例；保存生成新修订，两个 latest 实例立即显示新内容，固定旧修订实例保持不变；用旧编辑窗口再次保存时明确提示重新打开，不覆盖新修订。

22. **保存选中内容为公共组件**。操作：选中准备好的受管内容子树，点击「保存选中内容」，填写名称和分类并创建定义，再把新组件插入另一容器。预期：原位置及其撤销历史不发生变化；新实例保留原文字、行内样式、节点级样式、伪类和媒体查询的外观；定义源码不含原页面节点 ID，引用的项目图片仍可显示。

23. **转为本地组件并保持一次撤销**。操作：选中 latest 实例，在高级操作中选择「仅为当前内容创建本地副本」，随后撤销、重做并发布一个新的公共组件修订。预期：转换后的内容取得新的页面节点 ID，实例身份退休，静态模板文字进入页面正文；组件样式在本页保持，整次转换一次撤销即可退回，之后发布的新修订不影响本地副本。

24. **组件预览图与空占位**。操作：分别创建一个选择项目图片作为预览的组件和一个不选预览的组件，关闭并重开项目后查看「插入」页签。预期：前者显示受管项目图片，后者显示稳定占位；两者都不把本机路径或运行时 URL 写入组件定义。

## 第六轮：世界包与快照往返

**额外准备**：准备一个含公共组件两个修订、latest 与固定修订实例、组件预览图和资源依赖的项目；另保留一份组件修改前的快照和一份旧版对象层快照。

25. **公共组件随世界包完整往返**。操作：导出项目为 `.fcworld`，连续导入两次并分别打开导入项目。预期：两个项目各自获得不冲突的新组件 ID；全部修订、预览图、资源依赖及实例引用均保留，latest 实例显示最高修订，固定实例显示指定旧修订。

26. **无效组件定义只降级对应实例**。操作：导入一份组件定义未通过安全校验、但页面和其他数据合法的测试包。预期：导入完成并报告跳过的定义数量与原因；引用该定义的实例显示缺失状态，页面其余内容和其他组件正常显示。

27. **组件快照恢复只追加修订**。操作：为组件创建修订 1 并快照，再发布修订 2 并快照，回退到第一份快照后重新打开组件与页面。预期：旧修订不删除，新增一个内容等于快照状态的更高修订；latest 实例显示快照内容，数据库外键检查不报错。

28. **旧版快照保留当前组件**。操作：在已有公共组件的项目中恢复一份不含组件定义载荷的旧版快照。预期：当前组件定义及其资源仍保留，恢复结果明确报告保留数量；旧快照中的页面和业务数据按原有兼容规则恢复。

## 第七轮：可视编辑能力

**一次性准备**：在 macOS 调试打包版打开一个页面文档，页面中准备一个包含至少三个受管子节点的普通容器、一张图片和一个列表；让容器在移动基础中已有颜色和间距，但尚未设置桌面覆盖。保持右侧属性 Dock 可见，下面 3 项可连续完成。

29. **断点与交互态独立写回**。前置条件：打开编辑器后先确认默认档位显示为「移动基础」。操作：保持画布宽度不变，在「视图」页签依次切换移动基础与桌面覆盖，观察桌面档的继承来源；在桌面档覆盖颜色后清除覆盖。对一条分隔线在移动档设置留白，再切到桌面档修改线型，确认两档互不覆盖且功能区显示的值跟随当前档位。随后在属性 Dock 的颜色与效果页分别设置悬停和内部聚焦颜色。预期：断点切换不改变画布宽度；桌面未设置时明确显示继承移动设置，覆盖写入桌面媒体规则，清除后回落移动基础；分隔线的留白和线型分别写入当前档位且切换后正确回读；悬停写入 `(hover: hover)` 条件，内部聚焦写入 `:focus-within`，两者均不随断点切换而改变目标。

30. **Grid 轨道输入与断点隔离**。操作：选中普通容器，在属性 Dock 明确执行「转换为 Grid」，随后分别在移动与桌面档添加、删除和重排行列轨道，并切换固定值、随内容、比例分配和最小/最大轨道；调整行列间距及容器对齐，再撤销和重做。预期：转换前不显示轨道输入；转换作为一次独立历史步骤；两档轨道定义互不覆盖；每次轨道操作各形成一个可撤销步骤，相同值重放不增加源码；策略拒绝时显示原因且草稿不变。

31. **Grid 子项与任务窗格分层**。操作：选中 Grid 内的子节点，在右侧属性 Dock 设置行列起点、跨行跨列和子项对齐；再从功能区依次点击字体、容器排列、间距、Grid、图片说明与外观的「详细设置」。预期：子项位置和对齐写入当前断点并可一次撤销；功能区入口只切换到对应 Dock 页签与属性段，不立即改写草稿；不适用于当前节点的整段控件不出现，暂时不可用的命令保持禁用并通过悬停提示和读屏名称说明原因。

## 第八轮：编辑页骨架

**一次性准备**：在 macOS 调试打包版打开一个同时具有页面正文、词条元信息、结构化关系、正向链接和反向链接的词条，并让右侧页面属性 Dock 保持可见。下面 6 项可在同一窗口连续完成。

32. **常驻顶栏与功能区**。操作：进入编辑模式，在画布内滚动一篇超过一屏的页面文档。预期：词条顶栏与页面编辑工作条合并为同一行，功能区保持不动，只有画布区域滚动；保存状态和操作入口始终可见。

33. **整屏主体与窗口缩放**。操作：连续缩小和放大窗口，并分别滚动画布、属性 Dock 与关系页签。预期：主体始终占满可用窗口，不出现词条页面级纵向滚动条；三个需要滚动的区域各自滚动，功能区和状态栏不随画布移动。

34. **词条信息浮层沿用保存链路**。操作：从顶栏打开「词条信息」，修改摘要、标签、主图或词条类型后关闭浮层，再使用顶栏保存并重开词条。预期：浮层可由按钮、Esc 和关闭按钮正常开关；关闭本身不触发保存，修改仍进入当前词条的同一草稿与保存链路，保存重开后保持。

35. **两种模式都能打开关系面板**。操作：编辑模式下在右侧 Dock 的「属性 / 关系」页签之间切换并编辑一条关系；切到浏览模式后，从顶栏「更多」打开「词条关系」浮层。预期：编辑模式关系内容只在 Dock 内独立滚动，浏览模式关系内容在浮层中显示；两处展示同一份关系草稿，不出现第二份状态。

36. **浏览与编辑切换保持骨架稳定**。操作：在浏览和编辑之间反复切换，观察顶栏、正文起点和窗口边界。预期：浏览画布与页面编辑器都填满主体区；浏览模式不显示功能区，切换时顶栏位置与主体宽度不跳动，页面级滚动条不出现。

37. **画布快捷键、连续行内格式与 Enter 归一**。操作：在画布正文内按 ⌘S；拖选同一段文字后连续点击两次加粗；把光标放在普通段落中连按三次 Enter。预期：⌘S 只触发一次当前页面保存；第一次加粗后选区仍保持，第二次点击可取消加粗且不提示选区漂移；三次 Enter 依次分出三个新段落并把光标落到最新段落。另在表格单元格中分别按 Enter 与 Shift+Enter，预期两者都只在单元格内换行，不拆出表格外段落。

38. **段落内单段粘贴不分段**。操作：在普通段落中选中一段文字，粘贴一段不含空行的纯文本。预期：选中文字被一次替换，光标仍位于当前段落，页面不新增段落；一次撤销恢复粘贴前内容。
