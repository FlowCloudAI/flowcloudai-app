# 原生验收清单

> 状态：现行 ｜ 日期：2026-09-18

本清单只保留尚未由用户在原生产物中确认的项目。验证通过后直接删除对应项；命令行单测和浏览器预览不能替代这些检查。

## WebP 图片基线

1. **换图后预览刷新**。前置：在 macOS 调试打包版准备同一词条的两张内容不同的本地封面。操作：先选择第一张，等待列表派生图显示；再选择第二张并返回列表。预期：第二张显示新内容，不复用第一张缓存；原件文件仍可访问。
2. **失败占位与重试**。前置：在 macOS 调试打包版准备损坏图片或使派生目录不可写。操作：触发封面预览，再恢复文件或权限并重新触发。预期：失败时显示明确占位，不回退完整原图；恢复后能重新生成 WebP。
3. **发行构建不要求用户安装 C 开发环境**。前置：分别取得 macOS、Windows、Linux、Android、iOS 的发行构建，并使用未安装 C 编译器或 libwebp 开发头文件的目标设备。操作：安装、打开并触发封面派生。预期：应用可以使用静态链接的 libwebp 完成派生，终端用户无需额外依赖。
4. **动画与高位深样本观感**。前置：准备 GIF/WebP 动画、16 位 PNG 或 HDR 样本，以及 macOS 调试打包版。操作：将样本作为封面导入并查看预览或错误提示。预期：动画静态入口明确取首帧；请求动画播放时提示暂不支持；高位深/HDR 不会被悄悄降成错误颜色的普通预览。

## 画布层叠层

1. **macOS 最低系统版本**。前置：准备 macOS 12.2 与 12.3 测试环境及相同发行构建。操作：分别尝试安装并打开页面编辑。预期：12.2 不在支持范围；12.3 的画布保留项目、词条和组件层叠顺序。
2. **旧 Android WebView 关闭编辑入口**。前置：准备缺少 `CSSLayerBlockRule` 的 Android 系统 WebView。操作：打开词条并尝试进入页面编辑。预期：宿主显示升级系统 WebView 的提示，不能进入无样式画布。

## 页面文档节点身份

1. **分段与多段粘贴后的后续输入**。前置：使用 macOS 调试打包版打开含段落的页面文档并进入编辑模式。操作：在段落中间按 Enter，立即输入文字；再在任一段落粘贴包含空行的多段纯文本，并分别执行撤销、重做。预期：Enter 后的新文字只出现在新段落；多段粘贴按空行生成多个块，整次粘贴一次撤销即可全部退回，重做恢复原结果，其他源码不变。

## 页面文档 Office 功能区

1. **选区行内样式写回**。前置：使用 macOS 调试打包版打开含普通段落的页面文档并进入桌面可视编辑。操作：在画布中拖选一段文字，依次修改字号、加粗、斜体、下划线和主题颜色，再撤销、重做、保存并重开词条。预期：只修改所选文字，未选文字与未知合法源码保持不变；每项操作可撤销重做，重开后格式保留；切换词条或清空选区后控件禁用且不会写入旧节点。
2. **字号、加粗与对齐写回页面草稿**。前置：使用 macOS 调试打包版打开含段落的页面文档并进入桌面页面编辑的可视模式。操作：在画布中选中一个段落，分别使用“开始”功能区的字号、加粗和对齐命令，关闭后重新打开该词条。预期：每次操作只产生一次对应历史步骤，article.html/style.css 通过现有内核写回；重开后字号、字重和对齐保持，撤销与重做可恢复前后状态。
3. **容器布局字段写回页面草稿**。前置：使用 macOS 调试打包版打开含受管容器的页面文档并进入桌面页面编辑的可视模式。操作：选中容器，依次切换布局方式、分栏数、纵向对齐和横向分布，再执行撤销、重做并关闭重开词条。预期：控件只提供有限安全值，style.css 经现有内核写回且容器布局保持；作者已有复杂自定义值显示为自定义并保持不变。
4. **表格、列表与分隔线功能区**。前置：使用 macOS 调试打包版打开包含受管表格、列表和分隔线的页面文档并进入桌面页面编辑。操作：选中表格调整行列，选中列表切换项目符号/编号并新增列表项，选中分隔线修改线型和上下留白，再分别撤销、重做并保存重开。预期：每项命令都通过同一页面草稿内核写回，新增节点身份由宿主分配，源码结构与其他内容保持；图库页签仍显示明确的禁用原因。
4. **页面与视图功能区**。前置：使用 macOS 调试打包版打开可视页面编辑。操作：切换“页面”和“视图”页签，选择画布宽度，并在选中受管节点时执行页面内距。预期：画布宽度立即更新，页面内距经内核写回并可撤销；图层/布局线切换和开发者信息按各自状态提示处理。
5. **图片上下文功能区**。前置：打开含受管图片的桌面页面文档并选中图片。操作：切换“图片”页签，选择替换图片、打开替代文字或图注详情。预期：替换沿现有资产选择器和内核请求链执行；未选择文字时行内样式组保持禁用并显示原因。
6. **项目主题令牌功能区**。前置：使用 macOS 调试打包版打开带有效 `fc-project :root` 样式的页面文档并进入桌面可视编辑。操作：在“页面”页签选择“项目模板”，打开项目默认主题，修改正文颜色或内容宽度并应用，随后撤销、重做并切换页面预览。预期：请求只写入 `fc-project` 的 `:root` 令牌规则，CAS 版本过期时拒绝且不改草稿；修改进入统一页面草稿历史并可撤销，当前会话预览立即反映项目主题。项目模板的持久化与重开验证待项目模板存储接口接入后执行。
## 第四轮：公共组件最小纵向切片

**一次性准备**：在 macOS 调试打包版创建一个项目级公共组件定义，准备一个带公开属性和插槽的组件预览资产；再打开一个页面文档用于插入和重开检查。

15. **插入公共组件实例并保持重复实例隔离**。操作：在页面编辑器的「插入」页签按分类选择组件，向同一容器插入两次，分别填写公开属性和插槽内容，保存后关闭并重开词条。预期：两个实例各自保留页面节点 ID、实例 ID、属性和插槽内容；组件内部静态模板文本随定义展开显示，但不额外进入页面段落索引。

16. **公共组件修订与缺失状态**。前置：准备同一组件的两个修订，并让一个实例固定旧修订、另一个实例跟随最新修订；另备一份删除或不可读定义的页面草稿。操作：重开页面并查看三个实例。预期：固定旧修订继续显示旧模板，latest 实例显示最高修订，缺失定义保留实例引用并显示明确缺失状态，不静默删除。

17. **公共组件实例属性编辑与影响边界**。操作：选中组件实例，在属性面板修改定义声明的属性和样式变量，执行撤销、重做、保存并重开；尝试修改组件内部结构。预期：只改变当前实例的 `data-fc-prop-*` 与允许的样式变量覆盖，撤销重做和重开保持；内部结构操作提示“此组件来自公共模板”，编辑公共组件与转为本地组件均明确显示“暂未开放”。

18. **组件资源与删除保护**。前置：组件定义引用项目图片资产，页面中至少有一个实例。操作：尝试删除仍被实例引用的定义，再删除实例后重试删除定义，并删除项目。预期：有引用时删除被拒；解除最后引用后定义与资源依赖按对象层清理，项目删除不留下该项目组件定义或其无范围资产记录。
