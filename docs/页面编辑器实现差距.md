## 8. 已完全实现（经代码核对，尚未原生验收）

以下十一组已确认与参照仓等价或更强，不必重做。**全部为静态核对结论，均未在原生产物上验收。**

1. **功能区页签条与折叠优先级**：`document-editor/visual/documentRibbonModel.ts` 与参照仓同名文件仅差两行 import 路径，四个基础页签、六个上下文页签、分组优先级与折叠密度函数完全一致；`DocumentOfficeRibbon.tsx` 仅差一行 CSS import。
2. **图层大纲树的无障碍结构**：`components/layers/PageDocumentLayerTree.tsx:48-58,155` 是完整的 WAI-ARIA tree，roving tabindex 只留一个停靠点；`:115,129-136` 的折叠状态是组件内 `useState`，不写回草稿。
3. **详细设置入口只改界面状态**：`application/propertyDockNavigation.ts:1-42` 的导航意图不含任何编辑请求，消费处 `PageDocumentPropertiesPanel.tsx:328-337` 按页签定位属性段。
4. **预览画布宽度与修改生效范围是两组独立状态**：`components/PageDocumentEditor.tsx:188-189` 的 `previewWidth` 与 `editContext` 互不联动，入口也分离。
5. **纯文本粘贴、IME 组合输入、拖拽拒绝**：三项与参照仓行为一致。粘贴只接受纯文本并归一 `\r\n`；组合输入有起点快照、原节点回滚、`compositionend` 单次提交；拖入内容两仓都拒绝。
6. **源码模式的编辑基础**：语法高亮、行号、`lintGutter`、差异视图、诊断面板两仓等价，均为 CodeMirror 6 `basicSetup` 加 `lang-html|css`。
7. **块内换行的读写与键位全链路**：`domain/kernel/analysis/documentKernel.ts:657`、`patching/textContentPatches.ts:187`、`canvas/runtime/main.ts:382`、`styles/selectorMatcher.ts:398`、`analysis/textRangeAnalysis.ts:134,296` 已完整支持 `\n` ↔ `<br>`；Enter 写入块内换行，Shift+Enter 在可拆分文本块中拆出新块，表格单元格内两者均保留为块内换行。
8. **主仓强于参照仓的三项**：双链 `[[` 候选输入（`canvas/runtime/linkCandidate.ts:21-73`，参照仓无）；源码逐文件独立撤销栈；项目主题令牌任务窗格。
9. **Flex 子项尺寸**：父容器实际为 Flex 时，属性 Dock 提供九档基准宽度、剩余空间占比和空间不足收缩；其他布局不显示这组控件。
10. **元素宽度模式**：宽度使用「自动 / 设置宽度」单一模式切换，并提供 25% / 50% / 75% / 100% 快捷值；复杂源码在主动接管前保留。
11. **插入位置选择**：受管容器提供「容器内 / 容器后」，普通节点只显示「容器后」，未改变原有默认插入位置。

## 7. 核对方法与边界

第 1、2、5、6 节由人工逐条核对代码确认。第 3、4 节由 DeepSeek Harness 子进程四路并行核实参照仓与主仓差异，结果经人工抽验后入库——抽验覆盖 S1、S3、D13、D6、P5 五条，全部复现。只保留能给出双方文件行号的条目。

**全部为静态源码比对，未做运行时或原生界面验证。** 参照仓自己的移交清单也把界面项列为待原生验收（`app_entry_page_editor/docs/可行性结论与移交清单.md:27-50`），因此本文的「作者可感知差别」是从代码推导的预期，不是实测结论。

文件数对比可供参考但不能直接当作差距：参照仓 `document-editor/visual/` 下有 44 个 `.tsx` 控件组件，主仓对应能力分散在 `document-editor/visual/`（8 个）与 `page-document/components/properties/`（7 个），部分能力经合并实现。已核对**不构成缺口**的项：图层大纲树主仓有（`page-document/components/layers/PageDocumentLayerTree.tsx`）；阴影、旋转、渐变已并入 `StructuredPropertyControls.tsx`；功能区页签条与参照仓几乎逐行一致（`documentRibbonModel.ts` 仅差两行 import 路径）；源码模式的语法高亮、行号、差异视图、诊断面板两仓等价；纯文本粘贴、IME 组合输入、拖拽拒绝三项行为一致。

**主仓强于参照仓的地方**：双链候选 `[[` 输入（`canvas/runtime/linkCandidate.ts:21-73`，参照仓无）；源码逐文件独立撤销栈；项目主题令牌任务窗格。
