# 页面编辑器实现差距

> 状态：现行 ｜ 日期：2026-09-20

本文追踪 `app_main` 页面编辑器相对参照实现 `app_entry_page_editor` 的**作者可见能力差距**，以及用户在原生调试包上提出但尚未解决的问题。只记录有代码证据的条目，不收推测。

参照仓 `app_entry_page_editor` 是已结题的实验仓，其 `domain/` 内核已被主仓吃下（两边行数接近），差距集中在界面层与画布运行时。**内核已支持但界面未暴露**的条目优先级最高，因为补齐成本最低。

参照仓另有三份成文的界面规范，主仓移植时没有一并遵守，见第 4 节：`app_entry_page_editor/docs/可视编辑能力准入标准.md`、`docs/作者界面词汇对照表.md`、`docs/编辑器实现约束与机制说明.md`。
