# ADR 0002：页面文档存储与保存语义

- 状态：接受
- 日期：2026-09-14

## 决策

页面源码放在与领域对象明确关联的独立记录中。词条使用 `entry_page_documents(entry_id)`，项目首页使用 `project_home_documents(project_id)`；不把多种 owner 抽象成万能文档表。这样删除、权限边界、迁移和未来快照都能按领域外键表达，项目首页也不会误用项目默认模板身份。

词条页面记录保存 HTML、作者 CSS、Rust 生成的纯文本投影、`revision`、`modified_by` 与更新时间。项目样式和默认模板属于项目作用域，词条首次打开没有页面记录时由 Markdown 正文按空行分段并转义为纯文本段落生成初始 HTML。这是开发期初始化，不代表最终数据迁移决策。项目首页是独立记录，不修改项目简介；项目默认模板仍由后续模板接口管理。

每次保存都对目标记录独立执行 `expected_revision` CAS。成功后 revision 单调递增；过期 revision 拒绝。词条与本次改动的项目样式若同时提交，分别携带前置 revision，两个 CAS 均成功才提交，避免把一个作用域的成功伪装成联合成功。

请求携带作用域、目标、幂等键和请求摘要。相同键与摘要重试返回原提交回执且 revision 不增加；相同键不同摘要拒绝。回执在保存事务内按 `scope + owner_id` 分组，以 SQLite `rowid` 的插入顺序保留最新 64 条并删除更旧记录；清理不读取或改写文档当前状态。

`app_main` 的 Rust 校验模块在保存前解析 HTML/CSS，并从校验结果生成派生纯文本和合法 `<a href>` 出链目标。`core_world_data` 接收这些派生值并只负责事务存储，不再自行解析源码；出链仍只记录本项目且目标存在的词条，跨项目和死链跳过。删除词条由外键级联删除页面记录，同时写入墓碑记录；`modified_by` 指向本地主体。

同步接缝只在本 ADR 固定落点：资产引用使用稳定资产 ID；`space_id` 只确定未来归属字段的落点，当前页面文档表尚未实现该字段。今晚不实现同步系统，也不改变现有路径资产或移动端 Markdown。

## 已知缺口

FTS 仍索引 `entries.content`；CSV、快照和 `.fcworld` 暂不包含页面文档表。由后续计划中的搜索投影、导入导出和快照兼容步骤关闭，今晚不修改这些路径。
