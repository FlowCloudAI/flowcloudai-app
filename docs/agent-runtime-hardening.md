# AI Agent 运行时加固更新说明

> **状态**：现行
> **日期**：2026-09-09

## 自动精简对话记忆

- 新安装默认开启自动精简，触发阈值由 75% 调整为 65%。
- 每次发送前调用核心库的请求预检，按与真实发送一致的消息、冻结引用、动态指令、工具 schema、模型窗口和预留输出计算；模型未声明窗口时显示“未知”，不伪造百分比。
- 达到阈值时，先将较早对话整理成摘要，再创建新会话发送。摘要输入包含被覆盖回合的冻结引用，压缩边界另外保存当时仍有效的引用，恢复后紧跟摘要继续生效。
- 工具轮发生机械裁剪时，会在消息流提示，并在下次发送前优先尝试语义压缩。
- 已保存过该设置的用户继续使用自己的开关和阈值；可在“设置 → AI 配置”中随时关闭或调整。

## 回合上下文与持久化

- 用户正文和提交时上下文通过单个 Tauri 命令原子绑定，避免页面切换或异步读取把引用挂到错误回合。
- 项目、词条和文档正文属于参考资料，只随所属用户回合冻结并以 user 数据发送；应用感知提示、对话提示和权限说明属于可信指令，每次真实请求重新装配。
- 引用内容未变化时不重复保存；发生变更、恢复旧内容或明确移除时生成新版本。分支切换、重说和续写只读取当前分支快照。
- 对话格式当前为 schema v5。旧格式首次写回前保留一次 `.schema-v<旧版本>.json.bak`，正文经临时文件 `fsync` 后原子替换；快照写入和消息树/head 使用同一次运行时快照。

## 费用与月度预算

- 插件模型可同时声明 `prompt-price-per-m`、`completion-price-per-m` 和 `currency`；用户也可在“设置 → AI 配置”中按模型覆盖。
- 每次真实 HTTP 请求各保存一条用量记录，工具循环和重试不会再合并成一个逻辑轮次；`run_id + turn_id + request_id + attempt` 用于幂等去重。
- 记录供应商返回的缓存读取/写入 token；设置页同时显示 API 请求数、旧版轮次数、缓存命中量与可观测覆盖率。供应商未返回缓存字段时保持“未知”，不按零命中处理。
- 每次调用保存当时的单价快照，后续改价不会改写历史费用；缺少单价的记录显示为 `—`。普通输入单价不冒充缓存折扣价，因此已知缓存命中量也不会自动虚构节省金额。
- 不同币种分别汇总，不做汇率换算。月度预算默认在达到 80% 时提醒，但不会阻断 AI 服务。
