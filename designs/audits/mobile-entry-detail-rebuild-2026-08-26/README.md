## 一个值得记住的坑

`mobileAccessibility.css` 的公共触控兜底选择器是

```css
:root[data-fc-density="touch"] body :where(button, [role="button"], summary) { min-block-size: var(--fc-control-tap-min); }
```

`:where()` 本身零特异性，但整条选择器是 **(0,1,2)**。业务侧写 `.some-class button`（(0,1,1)）
**压不住它**，视觉高度会被静默还原成 48px。要压扁必须带上同一个 `:root[data-fc-density="touch"]`
前缀，并同时用 `::after` 把热区补回 48px——基线 §6.1 规则 2 要的是「扩热区」，不是「放大视觉」。

第 14/15 项都踩了这一条，第一次改完真机量出来还是 48px 才发现。
