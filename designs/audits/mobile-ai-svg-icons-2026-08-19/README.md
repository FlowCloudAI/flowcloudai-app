# 移动端 AI 操作图标审计稿

状态：**审计通过，已接入应用代码并完成 Android 真机视觉核对。**

本目录集中保存移动端 AI 页面五枚操作图标的候选矢量源文件与审计预览：

- `switch-plugin.svg`：模型菜单里的“切换插件”，主体略微加宽。
- `thinking.svg`：输入区“思考”开关。
- `mode-reader.svg`：读者模式，只读取资料。
- `mode-assistant.svg`：助手模式，写入前确认。
- `mode-writer.svg`：作家模式，可直接写入。
- `review-board.svg`：包含实际尺寸、放大轮廓、浅色与暗色背景的矢量审计板。
- `review-board.png`：审计板的固定像素预览。
- `android-actual-*.png`：Android 真机上的输入区、模型菜单与权限模式菜单截图。
- `design-qa.md`：设计稿与真机实现的对照结论。

## 统一约束

- 统一使用 `24 × 24` viewBox。
- “思考”同时使用实心填充和原有 `2.1px` 同色描边：填充避免内部形成两个三角形，描边保留完整外轮廓与圆角连接。
- 其余图标使用 `2.1px`、圆端点、圆连接的无填充描边。
- 颜色均继承 `currentColor`，最终由现有移动端语义颜色控制。
- 设计优先保证约 `18–20px` 实际显示尺寸下的辨识度。

## 当前提案语义

- 切换插件：插头，减少原块状图形类似“添加/医疗十字”的歧义。
- 思考：实心填充加描边的闪电，兼顾整体性与外轮廓重量。
- 读者：简化的打开书本。
- 助手：盾牌与对钩，表达受保护、写入前确认。
- 作家：简化铅笔，表达直接编辑和写入。

接入位置：五枚图标均位于 `MobileAiChatUi.tsx`，只影响共用这套页面代码的 iOS 与 Android 移动端。
