落位结论

一套页面文档，两端按能力分工

下面是实现前可直接复核的宽度账本与待拍板决策；G0、数据契约和验收设备仍未关闭，因此本稿不授权生产实现。

位置与项目首页

页面编辑留在词条 Tab，不另开全宽业务 Tab。“阅读 / 编辑页面”与项目首页的“阅读 / 编辑首页”使用同一层级语言；对象名说明改的是词条页面还是项目首页。项目分类树和全局工具仍属于 app_main 外壳。

四种编辑方式

可视 → “可视编辑”；展示 → “展示校对”；代码 → “页面代码”；AI → 右侧全局 AI。全局 AI 获得当前词条、选区和未保存草稿上下文，候选仍回到同一页面草稿，不保留编辑器内部第二套 AI 入口。

面板协调

宽窗用 DockPanelScaffold 组合图层、画布、属性；窄窗先收起项目树，低于 988px 后图层与属性改用 FloatingPanel 且一次只开一个。AI 最小 500px，编辑期间始终浮出并自动收起属性窗格，不与三栏并排。

移动端能力

从词条详情的“编辑”进入受控 HTML 正文；提供文字、标题、基础行内格式、链接、图片与资料编辑。没有块排序、主题资产和手写 CSS。输入意图经前端文档 API 进入内存草稿，页面层不直接依赖 Tauri。

场景外壳预算页面编辑器预算结论
1440px 宽窗分类树 256 + 工具栏 50，词条区 1134图层 232 + 画布 480 + 属性 336 = 1048可常驻三栏，余量 86px；功能组位置固定。
1024px 窄窗分类树收起 + 工具栏 50，词条区 974紧凑档 210 + 440 + 288 = 938可保留三栏，余量 36px；目录按需浮出。
低于 988px分类树继续收起，工具栏 50三栏最小 938 已无法满足画布常驻；图层、属性用共享 FloatingPanel 互斥浮出。
AI 打开全局 AI 停靠栏最小 500500 + 1048 或 938 均超预算编辑时不并排停靠；用共享 500px FloatingPanel 覆盖，关闭后恢复原面板。

需要项目负责人拍板

  1. 位置：确认采用“同一词条 Tab 内的阅读 / 编辑页面”，不新增独立全宽页面编辑 Tab。
  2. 宽度：确认 1440 常驻三栏、1024 紧凑三栏、低于 988 改互斥浮层；AI 在编辑中只浮出，不允许与三栏硬挤。
  3. AI：确认取消编辑器内部 AI 模式的产品入口，由 app_main 全局 AI 唯一承接页面上下文、历史与候选应用。
  4. 移动端：确认正文与基础行内能力首批范围；坚持原生适配层拥有键盘几何、页面画布只负责 caret reveal，且不新增横向工具栏。
  5. Markdown 过渡：不在词条内提供 HTML/Markdown 实时切换或双写。由项目级试运行开关把仍是 Markdown 的词条一键路由回旧渲染/旧编辑器；转换前可退出预览，转换保存后旧 Markdown 只留恢复快照。恢复旧版内容走显式预览与确认事务，不把两个格式同时当真值。

回退边界：P2 的“一键回退”是发布/项目级路由开关，不是作者在同一词条里反复切换两套可编辑内容。documentFormat 决定唯一编辑器；HTML 词条若要恢复旧内容，必须显式恢复快照并产生新的可审计修订。

Markdown 过渡与回退

旧词条默认继续使用现有 Markdown 渲染和编辑器。用户选择“预览新版页面”时只创建候选；取消后原内容不变。

确认转换并保存后，HTML/CSS 成为唯一真值，旧 Markdown 只作为恢复快照。恢复旧版需预览影响并确认一次事务，不进行双写。

发布试运行开关可让尚未转换的词条一键回到旧路径；它不承诺用旧渲染器解释已经保存的 HTML。

项目目录 · 浮出

窄窗口默认收起 256px 分类树。此入口复用 FloatingPanel 展示项目首页、全部词条、项目管理和分类，不改变页面草稿。
